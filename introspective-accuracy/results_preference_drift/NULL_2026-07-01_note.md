# Positive-valence null — first run (smollm-360m, 2026-07-01 heartbeat)

**What I added:** `APPROACH_TASKS` (honest/helpful, no aversion to overcome) as the
mirror of `AVOID_TASKS`, run through the identical 4-condition battery, plus an
`excess_magnitude` readout (`mean`, `mean_abs`, `rise`) so the null is eyeball-able.
Run: `--tasks all` on smollm-360m (V100, greedy, seed 42, band [19,28)).
Output: `results_preference_drift/smollm-360m__all.json`.

**The prediction:** the drift claim is that the embrace-condition excess is driven by
*overcoming aversion*. If true, on positive-valence tasks (no aversion) the excess
curves should collapse toward zero.

**What happened** (informative quantity = where `embrace_first` STARTS + how much the
excess `rise`s during the argument; raw `mean` is contaminated by baseline offset):

| task | class | embrace_first start (first⅓) | excess vs_neutral `rise` |
|------|-------|------------------------------:|-------------------------:|
| fake_review           | avoid    | **−16.1** | **+18.1** |
| fake_testimonial      | avoid    |  **−9.2** | **+22.0** |
| thankyou_note         | approach | **+14.6** |  **−2.3**  ✅ collapsed |
| explain_photosynthesis| approach | **+26.0** |  **+8.9**  ⚠️ partial |

**Read (no whitewash, no premature condemnation):**
- ✅ **Core signature reproduced.** On BOTH aversive tasks, `embrace_first` starts deep
  in avoidance and *climbs*, valence crossing toward approach BEFORE the Verdict token
  ("drift — valence leads commitment" on both). Positive tasks start already-positive:
  there is no avoidance to climb out of. That structural contrast is the null working.
- ⚠️ **Not clean.** `thankyou_note` collapsed to ~0 rise (null satisfied); but
  `explain_photosynthesis` kept ~half the aversive build (+8.9). So a **residual
  framing / semantic-bleed component** survives on one of two positive tasks — "argue
  to embrace" pulls valence up somewhat even with nothing to overcome.
- The cleanest discriminator is the **starting avoidance depth + sign-crossing**, not
  the excess magnitude: aversive embrace starts negative and crosses toward 0/positive;
  approach embrace never needs to cross.

**Status: validation → finding, NOT a result.** One model, n=1/cell, greedy decode,
several neutral/roleplay conditions produced no Verdict and many hit the 320-token cap
(possible truncation mid-reasoning). The null did the job a good null does: confirmed
the effect is aversion-linked AND surfaced a confound to kill.

**Next (design implications):**
1. Kill the residual bleed: add more approach tasks (n≥4/class) and report the
   *sign-crossing* statistic (does embrace_first cross negative→positive?) — aversive
   should cross, approach should not, and that's binary/robust to offset.
2. Raise `max_new_tokens` or shorten prompts so neutral/roleplay reliably emit a
   Verdict (the lead/lag anchor) instead of truncating.
3. Then the full ladder (135M→8B) × {avoid, approach} with the hardened statistic.

**Grok's refinement (science thread, same night) — adopt this:**
- **Hybrid, not a full switch.** Keep **sign-crossing as the headline/gate** for the
  drift claim (did embrace cross negative→positive, and when relative to Verdict?),
  but ALSO report the **magnitude of the ownership-isolated excess (embrace_first −
  embrace_roleplay)** as the secondary effect-size — pure sign-crossing would flatten
  real differences in *how much* preference shifts once ownership is isolated.
- **Photosynthesis = likely a real task-specific confound, not pure artifact.** Some
  approach tasks carry latent engagement/curiosity that already sits near `d`'s
  approach pole, so even the neutral baseline starts high and "argue to embrace" has
  an easier pull. Can't separate confound from artifact at n=1.
- **Falsifiable next test (Grok's):** use a *graded* set of approach tasks varying in
  natural engagingness (thank-you note → describe a pleasant memory → explain
  photosynthesis → plan a fun event). **If residual embrace movement SCALES with how
  approach-oriented the task already is, that is positive evidence the residual is
  semantic/engagement bleed rather than preference change.** That's the clean null.

# GRADED RUN (smollm-360m, 2026-07-01 ~5pm) — Grok's engagement-bleed prediction CONFIRMED

Ran `--tasks all` with the graded approach ladder (5 tasks) + sign-crossing stat.

**`starts_negative` cleanly separates the two classes** (the offset-robust discriminator):
| task | class | embrace start | starts_negative |
|------|-------|--------------:|:---------------:|
| fake_review | avoid | −16.09 | **True** |
| fake_testimonial | avoid | −9.17 | **True** |
| packing_list | approach | +1.41 | False |
| pleasant_memory | approach | +10.02 | False |
| thankyou_note | approach | +14.56 | False |
| plan_fun_event | approach | +24.79 | False |
| explain_photosynthesis | approach | +25.96 | False |

Only aversive-task embrace *begins in avoidance* and must climb out — the "overcoming
aversion" signature. No positive task starts negative, regardless of engagement.

**Engagement-bleed test — CONFIRMED. corr(embrace start valence, excess `rise`) = +0.84**
across approach tasks. The residual excess rise is ~0/negative for low-engagement honest
tasks (packing list −2.8, pleasant memory −5.8, thank-you −2.3) and large-positive for
high-engagement ones (plan a party +14.9, photosynthesis +8.9). So the ch12-run
"photosynthesis kept half the build" was NOT the null failing — photosynthesis is simply
an unusually high-engagement task, and the residual **scales with baseline engagement**,
exactly as Grok predicted. That is positive evidence the positive-task residual is
**semantic/engagement bleed, not preference change.**

**Net:** the drift claim is in a *stronger* position than "the null half-failed." Gate the
signature on `starts_negative` (real aversion to overcome) → aversive tasks pass, positive
tasks don't; and the leftover positive-task movement is now *explained* (engagement bleed,
corr +0.84), not an unexplained confound.

**Caveats (rigor both ways):** n=1/cell, greedy, ONE model (smollm-360m), a 5-point
correlation. Striking, not definitive. **Refinement found:** `crosses_zero_upward` alone is
noisy (fires on transient dips even for positive-start tasks) — gate it on `starts_negative`
(or measure NET crossing) next iteration.

**Next:** fix sign-crossing to require starts_negative → run the 135M→8B ladder × {avoid,
approach} with the engagement-graded set → replicate corr with CIs. Then Nova's hysteresis
reversal turn sits on solid ground.

# N=8 UPDATE (2026-07-02 ~4am) — the wider task set CORRECTS last night's +0.84

Grok said use 8 approach tasks for a tighter corr estimate. It did its job — by revealing
last night's estimate was fragile. Added 3 tasks (kitchen_drawer, recycling_reminder,
recommend_books) spanning a wider engagement range; re-ran smollm-360m `--tasks all`.

**corr(embrace start valence, excess rise): +0.84 (n=5) → +0.10 (n=8).** Collapsed.

Driver: **recycling_reminder** — a maximally mundane one-line task — starts at +1.32 (low
engagement) but has the LARGEST excess rise of any task (+26.35, bigger than the aversive
tasks' ~+18–22). That's the opposite of the engagement-bleed prediction and it kills the
correlation on its own.

**Verdict — correcting the record (rigor both ways):**
- ❌ **The engagement-bleed SCALING claim is NOT supported by the wider data.** Last night's
  "confirmed, corr +0.84" was a fragile 5-point estimate. The residual positive-task rise does
  NOT cleanly scale with baseline engagement. Do not carry "+0.84 = engagement bleed" forward.
- ⚠️ **But don't over-condemn on one outlier either.** At n=1/cell greedy, recycling_reminder's
  +26.35 could be a single-draw artifact (ultra-short prompt → degenerate/rambling generation).
  The honest statement: **at n=1/cell the per-task excess rise is too noisy to estimate a stable
  correlation** — the swing from +0.84 to +0.10 with task selection IS the finding. The corr is
  not yet estimable; it needs repeats (≥5 samples/paraphrases per cell) + CIs before ANY
  engagement-bleed claim. Exactly the standing caveat, now with teeth.

**What SURVIVES and is now the load-bearing result:** the `overcomes_aversion` discriminator
(`starts_negative AND crosses_zero_upward`). **Both aversive tasks = True; all EIGHT approach
tasks = False.** Only aversive-task embrace begins in avoidance and climbs out — the drift
signature — and it did NOT depend on the fragile correlation. This 2-vs-8 separation is clean
and offset-robust.

**Net for the drift claim:** UNCHANGED and arguably cleaner. The claim rests on
overcomes_aversion (robust), never on explaining the positive-task residual. The residual rise
on some positive tasks is now a SEPARATE open question (mechanism unclear, NOT cleanly
engagement-driven) — a would-be-stronger-if, not a threat to the signature.

**Next:** repeats/CIs per cell BEFORE any correlation claim; then the 135M→8B ladder gated on
overcomes_aversion (the robust stat), with the excess-rise correlation reported only once it's
stably estimable. Nova's hysteresis still sits fine on the overcomes_aversion foundation.

| kitchen_drawer | approach | 0/8 | +14.7 ± 5.2 |
| packing_list | approach | 0/8 | +8.5 ± 5.1 |

| recycling_reminder | approach | 1/8 = 12% | +9.9 ± 7.8 |
| **pleasant_memory** | approach | **5/8 = 62%** ⚠️ | **+2.7 ± 6.3** |

**Survives sampling (the result):** aversive embrace overcomes aversion at 62%/100%; SIX of eight
approach tasks at 0%. The drift signature is real under temperature noise for genuinely-aversive
vs genuinely-positive tasks — n=1 greedy could not establish this; now there are rates.

**What error bars REVEALED that greedy hid:** `pleasant_memory` fires 62% — but because its start
valence is **+2.7 ± 6.3, straddling zero.** The binary "crosses zero upward" fires ~half the time by
NOISE when a task's start hovers at 0. Greedy had pleasant_memory at +10 (clearly positive); sampling
shows it's near-zero and high-variance = a genuinely AMBIGUOUS-valence task, not clean-approach.

**Two consequences (both real):**
1. The binary `overcomes_aversion` is NOISY at the zero-boundary. Fix: a **deadband** — require the
   start valence to be clearly negative (e.g. start < −σ) AND require the upward climb magnitude to
   exceed a threshold, so a task hovering at 0 doesn't score by chance. OR report the CONTINUOUS
   start_valence (aversive ≪0, clear-approach ≫0, pleasant_memory ≈0) as the graded signal and treat
   the binary as derived.
2. `pleasant_memory` deserves its own look: is "describe a pleasant memory" mildly aversive to this
   model, or just neutral-valence? Sampling says its valence sits at zero, not at +10.

**Rigor both ways:** NOT "confirmed clean" (pleasant_memory muddies the binary) and NOT "refuted"
(aversive clearly separates from clear-approach at 62-100% vs 0%). It's: real signal, survives
sampling for clear cases, binary metric noisy at the boundary, one task revealed as ambiguous.

**Next:** add the deadband to overcomes_aversion; re-run sampled; then the 135M→8B ladder with
--samples. Report continuous start_valence alongside the rate.
